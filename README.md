# Tenis Satalice – návrhy nového webu

**Náhled:** https://petrluxa.github.io/Satalice/

Dva návrhy úvodní stránky nového webu Tenisového klubu SK Satalice. Obsah je stejný, každý návrh stojí na jiném obrazu:

- **Kurt je připraven** – pohled shora na antukový dvorec, který se před očima nakropí, urovná a nalajnuje
- **Stíny na zdi** – odrazová stěna v podvečerním slunci a tři stíny hráčů: starší, mladší, nejmladší

Úvodní obrazovka se po otevření sama rozehraje, tlačítkem „Přehrát úvod“ se nástup pustí znovu.

Texty, ceny, jména a fotografie pocházejí ze současného webu klubu.
